02 · Workshop · attended

Second Brain: an AI assistant you can shape.

The idea

A second brain is a folder of Markdown files and an agent that can read them. No database, no migration project, no proprietary memory layer: the folder is the product.

Maxime Gaudin’s starter repo provides the scaffold, bootstrap prompt, tone-of-voice file, and composable skills.

What I took away

When the answer is wrong, fix the instruction that produced it. Personalization is an operating system, not a one-off prompt.

Plain filesComposable skillsHuman approval
I used the workshop approach to install skills, build context, and make the assistant useful from inside the folder.

04 · Not attended · researched

When code is cheap, governance is the hard part.

The workshop’s premise

Quality Clouds’ hands-on session starts with a small Node task API and asks an AI coding tool to extend it. The point is not to generate code; it is to determine whether the team can defend what came back.

Participants fork the repo, complete six tasks, use catch-up branches, and connect a free Norma workspace through MCP and OAuth.

↗ Open the workshop repository

The practical loop

Generate → inspect → test → audit → link the repository → keep a record. Governance becomes an engineering workflow rather than a policy document read after the incident.

MCPOAuthNorma
The question is not “can AI write this?” It is “can we explain, test, own, and monitor what it wrote?”

07 · Inspiration

Digital twins can help protect what time cannot.

The intelligence of digital twins

Andrea Louis and Yves Ubelmann of Iconem presented how photogrammetry, 3D models, spatial knowledge, and AI can document threatened heritage sites and make them accessible through immersive experiences.

Saint Peter’s Basilica resources provide a concrete example: an interactive digital experience and a video about digitally preserving the basilica with AI.

AI here is not replacing heritage expertise. It is extending the evidence available to it.
08 · Main stage

Innovation is not only a technology story. It is a work story.

Innovation: The engine for global prosperity · Kamran Elahian · 22 September

“Expect new jobs to emerge—and expect some of the jobs we know today to disappear.”

The session connected innovation with purpose, learning from failure, and the unconventional people who drive change. My personal takeaway was to expect roles to be redesigned as AI changes the cost of production.

Prosperity comes from turning change into capability, not from pretending the old shape of work will remain.
09 · Clarity

Technical complexity only matters when people can act on it.

AI for Clarity · Iñigo Antolín and Andy Storch · Workshop Room B · 23 September

Storyteller prompts

Start with the audience, the decision they need to make, the context they already have, and the one action the story should unlock.

Then ask AI to remove jargon, surface the tension, choose the right analogy, and produce a version that can be challenged.

Tools I saved

Storytelling Master in ChatGPT is a practical prompt-based tool for turning technical material into a clearer narrative.

↗ Open Storytelling Master
Clarity is not simplification for its own sake. It is respecting the next person’s attention enough to make the decision visible.
10 · What I brought back

The useful unit is not the model. It is the loop.

01ContextGive the system the files, constraints, audience, and purpose that make an answer specific.
02EvidenceUse local runs, realistic examples, tests, and traceable sources to make claims inspectable.
03JudgmentKeep the human decisions visible: approve, challenge, govern, and decide what ships.

Build the system around the intelligence.
